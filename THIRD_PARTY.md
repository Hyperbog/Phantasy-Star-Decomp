# Third-party source and commercial game material

- **Sega Phantasy Star:** original commercial ROM and derived game machine code/graphics/music/text are not distributed or committed. Users must supply an authorized copy locally. Autogenerated `generated/ps1en_*.c` is a ROM-derived representation and is excluded from Git.
- **smsggrecomp** (https://github.com/mstan/smsggrecomp): external upstream project. The uploaded 2026 source ZIP contains no top-level LICENSE; this repository includes only the specifically required small source patches as a reproduction artifact, not the external source tree. Publication or redistribution of the patched engine needs separate rights assessment.
- **z80-recomp-core** (https://github.com/mstan/z80-recomp-core): external dependency with PolyForm Noncommercial terms; read the dependency's original LICENSE for obligations and limits.
- **Superzazu Z80**: vendored within the external SMS engine, under MIT terms (license supplied by upstream).
